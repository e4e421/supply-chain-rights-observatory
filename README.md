# Supply Chain Rights Observatory

Public, source-traceable research intelligence for **European supply chain sustainability, human rights, labour standards and responsible procurement**. Independent research resource; not affiliated with ETH Zurich or any listed institution.

**Website:** https://e4e421.github.io/supply-chain-rights-observatory/

## Contents

- `/docs`: static, mobile-friendly site (no frontend API keys, third-party JS, cookies or trackers).
- `/docs/data/latest.json`: public research leads (generated by Actions).
- `/docs/data/references.json`: manually curated authoritative sources and their research use.
- `/docs/data/archive-summary.json`: permanent public record counts; `/docs/data/source-health.json`: source review status.
- `/sources/queries.json`: public keyword monitoring configuration.
- `/sources/registry.json`: editorially curated source register (17 sources at initial migration); `/sources/candidates.json`: review queue, never auto-approved.
- `/data/archive/YYYY-MM.jsonl`: permanent public-metadata-only monthly archive; `/data/archive/manifest.json`: counts, partition digests.
- `/data/events/curated.json`: manual event linkage scaffold, empty until verified case assessments exist.
- `/scripts/update_data.py`: conservative RSS and Crossref collector (Python standard library only).
- `/scripts/archive_data.py`: stable ID verification, idempotent monthly archiving and SHA-256 manifest.
- `/scripts/source_governance.py`: source integrity registry, quarterly review reminders and weekly domain-restricted HTTPS reachability checks (not credibility checks).
- `/scripts/export_archive_csv.py`: offline English-schema CSV export with spreadsheet-injection protection.
- `/scripts/validate_data.py`: fail-closed JSON/schema/URL checks.
- `/tests`: offline unit tests using fixture payloads (no external requests).
- `/.github/workflows/refresh-and-publish.yml`: scheduled refresh, validation and Pages deployment.
- `/SECURITY.md`: security model, threat boundaries and recommended account settings.


## Multilingual research interface (English canonical)

The research portal supports **English (default)**, **Traditional Chinese**, and **German**. User-visible copy is authored in English, with audited translation mappings in `docs/i18n.js`. The public feed's source names and descriptions are generated in English, and legacy Chinese records remain readable through backwards-compatible display aliases.

- Switch using the header selector, or share links with `?lang=en`, `?lang=zh` or `?lang=de`. Language choices are saved locally in the browser; no account, cookies or analytics services are involved.
- The page language and date formatting adapt to the selection. The explicitly labelled last-update time remains in the **Asia/Taipei** time zone.
- Original newspaper and academic publication titles remain in the language in which they were published. They are **not automatically machine-translated**.
- UTF-8 CSV downloads retain canonical English field names, stable topic identifiers and original titles for reproducible collaborative analysis. Exported data is not translated in a way that might change its meaning.
- Static site copy, source descriptions, live status messages, research themes and source cards are translated. The collection workflow remains language-independent and requires no translation API key.
- The frontend's language preference uses localStorage only for this preference. It does not identify visitors or send telemetry.


## Two public fronts: visitor portal and professional workbench

- **Visitor portal:** https://e4e421.github.io/supply-chain-rights-observatory/ — introductory research context, latest headlines, references, historical archive, methods and limitations.
- **Professional workbench:** https://e4e421.github.io/supply-chain-rights-observatory/workbench/ — high-density table, three-pane inspection, latest/monthly/combined search, AND/OR/phrase queries, editable filters and visible columns, date sorting, DOI/record ID lookup, public provenance and source-health checks.
- Bookmark \`/workbench/\` for a fast daily research entry. Shareable query URLs retain filters; URL query strings must not include private/sensitive data. Saving named views uses browser **localStorage only**, not the server, repository or cloud. These views are not synced across devices.
- Keyboard controls: \`/\` to focus search, \`J/K\` to navigate records, \`Enter\` to inspect the selected record, and \`Escape\` to clear selection. Dense and comfortable table modes are available.
- **Combined archive search:** monthly static JSON shards are loaded on demand. A conservative 24-shard / 10,000-record browser limit prevents runaway loads; when exceeded, the interface explicitly labels results as **partial**. The canonical JSONL remains the research-grade export source.
- CSV export contains filtered publication metadata with stable English column names and spreadsheet-injection protection. Articles are not incidents, and an unverified publisher hint is not an authenticated source.
- No new API keys, analytics, authentication, server process, external JavaScript or private data stores are introduced. Both fronts share the same GitHub Pages static deployment.

## Manual setup (one-time)

1. Open **[GitHub repository Settings → Pages](https://github.com/e4e421/supply-chain-rights-observatory/settings/pages)**.
2. Under **Build and deployment → Source**, select **GitHub Actions** (not **Deploy from a branch**), then save if prompted. This is important: commits made with the GitHub Actions `GITHUB_TOKEN` do not automatically trigger Pages branch publishing.
3. Open **[Actions](https://github.com/e4e421/supply-chain-rights-observatory/actions)**. If Actions are disabled, enable them for this repository. Select **Refresh public intelligence and deploy** → **Run workflow** → `main` → **Run workflow**.
4. Check that the `collect` and `deploy` jobs finish successfully. The initial collection needs access to external sources; partial source failures show a warning and are not silently treated as complete coverage.
5. View the site at **https://e4e421.github.io/supply-chain-rights-observatory/** or use **Settings → Pages → Visit site**. It can take several minutes for the initial deployment.
6. Optional but recommended: **Settings → Actions → General**: use least-privilege workflow permissions; review **SECURITY.md** and protect your account with 2FA. No API key, Personal Access Token or paid service is needed.

The scheduled data collection runs daily at **06:23 Asia/Taipei** (`22:23 UTC`, `cron: 23 22 * * *`). An additional **weekly source-reachability check** runs Mondays at **06:43 Asia/Taipei** (`22:43 Sunday UTC`) using approved institutional URLs only. GitHub scheduling is best effort: execution can be delayed, and scheduled workflows in public repositories can be disabled after 60 days of inactivity. The website reports **actual** successful collection time.

## Long-term research database and source governance

The long-term archive is **already initialized**; existing public records were backfilled from the latest snapshot, and future new records are appended by the daily collection workflow. The current user-facing snapshot remains deliberately bounded (150 days and 240 records). The archive **does not expire on this snapshot schedule**.

- One immutable first-observation entry per `record_id` in `data/archive/YYYY-MM.jsonl`; stable IDs use the existing 18-character public SHA-256 prefix. Collision/fingerprint mismatches fail closed. Each record has `first_seen` and `event_id: null`.
- `manifest.json` enumerates monthly files with SHA-256 digests, sizes and record counts. **Integrity checks are not authenticated third-party signatures**; project administrators can still alter history.
- **Article identity is not incident identity.** A separate editor-reviewed case study is required before allocating any `event_id`. Headlines and reporting volume are not proof of violations.
- Source registry tracks `verified_on`, `review_due`, methodological provenance and approval status. Pre-existing sources not reverified in this upgrade are explicitly flagged for editorial re-review.
- Weekly availability tests use HTTPS HEAD and a hard-coded host allowlist. HTTP 403, 405, timeouts and redirects only inform reachability; they do not determine source credibility, and they never automatically promote new organisations.
- At least quarterly, manually review institutional status, editorial independence, dataset revisions, data rights and methods, source links, false positives and event coverage.
- On-demand local CSV: `python3 scripts/export_archive_csv.py --output /tmp/scro-public-archive.csv`; English field identifiers remain stable for R, Python, DuckDB and Excel.
- Monthly off-repository backups to an access-controlled storage location are recommended. GitHub commit history alone is not adequate for disaster recovery.
- This is an **open-source, public-records repository**, not a secure repository for personal identities, confidential company records, sensitive interviews or API secrets.

See [data architecture](docs/ARCHITECTURE.md) and [source issue templates](.github/ISSUE_TEMPLATE/new-source.yml).

## Data integrity and research interpretation

- **Discovery feeds**: targeted Google News RSS queries are used only to find possible leads. A mention is *not* verification or an allegation endorsed by this project. Links may point through the aggregator and should be followed to the primary source.
- **Academic metadata**: Crossref bibliographic API is queried for potential papers; a record is not evidence of peer review, validity, causal identification or publication quality.
- **Official documents**: CSDDD and EU Forced Labour Regulation dates are presented as **manually verified reference text**, not as machine-parsed legislation. Verify versions and national transposition before relying on them in a study.
- **Coverage limitations**: Search-engine ranking, language, sampling and reporting bias make the feed incomplete. Missing news does not imply no risk, and a higher count does not mean higher violation prevalence.
- **Data fields**: original title, published date, link, monitoring source, evidence class, topics and DOI (where relevant). No full copyrighted articles are reproduced.
- **When feeds fail**: previously captured leads up to 150 days old are retained. The status becomes `partial` or `failed`, and the site clearly warns if the last successful collection becomes stale.
- **Download**: the website offers an Excel-compatible UTF-8 CSV; spreadsheet-formula injection is neutralized by escaping leading spreadsheet operators.

## Update research focus

Edit `sources/queries.json`, add or revise keywords and query descriptions. Every query is public, and is intended for **information discovery**; changes should be reviewed for bias and false positives. To propose a new source, use the [source proposal form](https://github.com/e4e421/supply-chain-rights-observatory/issues/new/choose). An editor checks original publisher authority, data method, licensing, geographic coverage and reliability before updating **both** `sources/registry.json` and `docs/data/references.json`. Source availability does **not** validate a claim. The automated collection hosts remain explicitly allowlisted; adding a source to the directory does not enable a new crawler.
