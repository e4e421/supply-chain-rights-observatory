# Supply Chain Rights Observatory

Public, source-traceable research intelligence for **European supply chain sustainability, human rights, labour standards and responsible procurement**. Independent research resource; not affiliated with ETH Zurich or any listed institution.

**Website (after enabling GitHub Pages):** https://e4e421.github.io/supply-chain-rights-observatory/

## Contents

- `/docs`: static, mobile-friendly site (no frontend API keys, third-party JS, cookies or trackers).
- `/docs/data/latest.json`: public research leads (generated by Actions).
- `/docs/data/references.json`: manually curated authoritative sources and their research use.
- `/sources/queries.json`: public keyword monitoring configuration.
- `/scripts/update_data.py`: conservative RSS and Crossref collector (Python standard library only).
- `/scripts/validate_data.py`: fail-closed JSON/schema/URL checks.
- `/tests`: offline unit tests using fixture payloads (no external requests).
- `/.github/workflows/refresh-and-publish.yml`: scheduled refresh, validation and Pages deployment.
- `/SECURITY.md`: security model, threat boundaries and recommended account settings.

## Manual setup (one-time)

1. Open **[GitHub repository Settings → Pages](https://github.com/e4e421/supply-chain-rights-observatory/settings/pages)**.
2. Under **Build and deployment → Source**, select **GitHub Actions** (not **Deploy from a branch**), then save if prompted. This is important: commits made with the GitHub Actions `GITHUB_TOKEN` do not automatically trigger Pages branch publishing.
3. Open **[Actions](https://github.com/e4e421/supply-chain-rights-observatory/actions)**. If Actions are disabled, enable them for this repository. Select **Refresh public intelligence and deploy** → **Run workflow** → `main` → **Run workflow**.
4. Check that the `collect` and `deploy` jobs finish successfully. The initial collection needs access to external sources; partial source failures show a warning and are not silently treated as complete coverage.
5. View the site at **https://e4e421.github.io/supply-chain-rights-observatory/** or use **Settings → Pages → Visit site**. It can take several minutes for the initial deployment.
6. Optional but recommended: **Settings → Actions → General**: use least-privilege workflow permissions; review **SECURITY.md** and protect your account with 2FA. No API key, Personal Access Token or paid service is needed.

The scheduled job runs every day at **06:23 Asia/Taipei** (`22:23 UTC`, `cron: 23 22 * * *`). GitHub scheduling is best effort: execution can be delayed, and scheduled workflows in public repositories can be disabled after 60 days of inactivity. The website reports **actual** successful collection time.

## Data integrity and research interpretation

- **Discovery feeds**: targeted Google News RSS queries are used only to find possible leads. A mention is *not* verification or an allegation endorsed by this project. Links may point through the aggregator and should be followed to the primary source.
- **Academic metadata**: Crossref bibliographic API is queried for potential papers; a record is not evidence of peer review, validity, causal identification or publication quality.
- **Official documents**: CSDDD and EU Forced Labour Regulation dates are presented as **manually verified reference text**, not as machine-parsed legislation. Verify versions and national transposition before relying on them in a study.
- **Coverage limitations**: Search-engine ranking, language, sampling and reporting bias make the feed incomplete. Missing news does not imply no risk, and a higher count does not mean higher violation prevalence.
- **Data fields**: original title, published date, link, monitoring source, evidence class, topics and DOI (where relevant). No full copyrighted articles are reproduced.
- **When feeds fail**: previously captured leads up to 150 days old are retained. The status becomes `partial` or `failed`, and the site clearly warns if the last successful collection becomes stale.
- **Download**: the website offers an Excel-compatible UTF-8 CSV; spreadsheet-formula injection is neutralized by escaping leading spreadsheet operators.

## Test locally

```bash
python3 -m unittest discover -s tests -v
python3 scripts/validate_data.py
python3 -m http.server 8000 --directory docs
# Open http://localhost:8000
```

The first actual network refresh is designed to run in GitHub Actions. To run it locally with public network access:

```bash
python3 scripts/update_data.py
python3 scripts/validate_data.py
```

## Update research focus

Edit `sources/queries.json`, add or revise keywords and query descriptions. Every query is public, and is intended for **information discovery**; changes should be reviewed for bias and false positives. To add verified authoritative sources, edit `docs/data/references.json` and review original URLs.
