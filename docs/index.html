01 · 資料來源

公開 RSS 發現線索、Crossref 書目 API 與人工核對的官方連結；不擷取登入內容或私人資料。

02 · 資料處理

去重、日期正規化、關鍵字初步分類；保留原始標題、來源與外部連結，不進行未經驗證的指控摘要。

03 · 更新與失效

GitHub Actions 預定每日臺北時間 06:23 執行。排程可能延遲；失敗時以實際上次成功時間顯示資訊時效。

04 · 隱私與資安

無登入、Cookie、分析追蹤或前台 API 金鑰。公開資料不可存放研究者個資、未公開訪談及保密協議資料。
