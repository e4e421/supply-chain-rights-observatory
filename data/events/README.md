# Manually reviewed research events

`curated.json` intentionally starts with empty `events` and `links`.

- A `record_id` identifies one publication / discovery record, not an incident.
- An `event_id` requires documented editorial assessment of underlying allegations, actors, times, locations and whether multiple reports describe the same underlying event.
- Do not infer an event ID from the title, company name, headline count, publication date, similarity model or a single source.
- `event_id` must not be used as evidence that a human rights violation was adjudicated or proved.
- Any future linking schema should include reviewer role (not personal identity), decision date, supporting public evidence, confidence and correction history.
